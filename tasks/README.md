# Weekly tasks

[Back to the guide](../README.md)

Each week we add tasks that use what you have just been taught, on the simulator’s data. Some build on the project you registered in week 1; others are short exercises of their own. Do them in the simulator, keep your scripts in your project folder, and export only what a task asks you to.

| Week | Topic | Task |
| --- | --- | --- |
| 1 | Pre-registration | [Register a project, and hand in the PDF of your approved proposal](week-01-pre-registration.md) |
| 2 | Describing data, distributions and uncertainty | [Describe the cohort, look at distributions, and put confidence intervals on estimates](week-02-describing-data.md) |
| 3 | Testing hypotheses and comparing groups | [Compare groups, test tables of counts, and check genotypes for Hardy–Weinberg equilibrium](week-03-testing-hypotheses.md) |
| 4 | Regression | [Fit linear and logistic regressions, with genotypes as predictors, confounders and interactions](week-04-regression.md) |
| 5 | Genome-scale inference | [Run a genome-wide association study, from quality control to multiple testing and linkage disequilibrium](week-05-genome-scale-inference.md) |

## Working on the tasks

- **Stay within your plan.** When a task touches your own project, check it against your registered proposal. If you change the plan, add a dated line to `changes.md` saying what changed and why.
- **Keep scripts, not console history.** Save your R or Python code in your project folder, so that you can run it again from the start.
- **Results leave only through the Airlock**, under the training project RR4001, and only when a task asks you to export something.

## For the course team: adding a week

1. Copy [`week-template.md`](week-template.md) to `week-NN-short-name.md` (for example `week-02-describing-data.md`) and fill it in.
2. Add a row for it to the table above, and to the table in the [main README](../README.md).
3. **This repository is public: no answers, expected values or hints about what the data contain.** Questions, tables to start from and methods are fine; results belong in the course team’s private notes.
